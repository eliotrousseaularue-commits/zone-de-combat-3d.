# Zone de Combat 3D — version multijoueur

Jeu 3D jouable dans Safari sur iPhone, avec arène, commandes tactiles, joueurs connectés et armurerie locale.

## Déploiement Render
- Runtime : Node
- Build : `npm install`
- Start : `npm start`
- Port : fourni automatiquement par Render.

## Limites du prototype
Le multijoueur synchronise les positions et les tirs de base. Il n'y a pas encore de comptes, de matchmaking, d'anti-triche, de chat vocal ni de sauvegarde cloud. Les crédits et armes sont enregistrés sur l'appareil. Le rendu 3D utilise Three.js depuis un CDN et nécessite Internet.
